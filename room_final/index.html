제품의 소비 전력과 한 달 사용시간을 정해 보세요. 계산은 자동으로 해요.

평가 기준시간보다 짧게 설정해도 절약 점수는 더 올라가지 않아요. 실제 사용량과 요금은 선택한 시간으로 계산해요.

소비 전력이란?

전기 기구가 1초 동안 사용하는 전기 에너지의 양. 단위는 W(와트)예요.

전기 에너지는 어디로?

사용 목적에 따라 빛에너지, 열에너지, 운동 에너지 등으로 전환돼요.

효율적인 선택

성능과 사용시간이 같다면 소비 전력이 작은 제품이 에너지를 적게 사용해요.

한 달 전기 에너지 사용량 · 자동 계산
한 달 예상 전기요금 · 게임용
자동 계산과 게임 요금 기준 보기

1 W = 1 J/s를 이용해, 사용시간을 초로 바꾸어 전기 에너지(J)를 자동 계산합니다. 학생이 계산식을 풀거나 값을 입력할 필요는 없어요.

게임 요금 = 기본 1,000원 + 전기 에너지 1,000,000 J당 55원(최종 금액에서 반올림). 실제 전기요금이나 누진제를 재현한 값은 아닙니다. 소비 전력과 시간도 학습용 예시입니다.

냉장고는 전원을 켜 놓은 시간이 아니라 압축기가 실제로 작동한 시간을 설정합니다. 단순히 플러그를 뽑아 절약하지 않아요.

필수 가전과 추가 가전 3종 이상은 제출 조건이에요. 추가 가전은 각각 월 3시간 이상 사용하도록 설정해요. 필수 가전에는 별도 점수가 없어요. 구입비·전기요금·가구의 방향은 점수에 포함하지 않아요. 무료 가구는 색상과 공간 활용을 포함한 모든 점수 계산에서 제외해요. 입주 완료 시 아래 기준으로 자동 채점하며, 결과 화면에는 총점만 표시해요.
